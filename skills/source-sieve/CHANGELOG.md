## 1.1.1 (2026-10-21)

- Example 1 now labels a narrowed superlative Partly supported, matching references/labels.md.
- Step 4 and the decision order in `references/labels.md` now carry the exception already in
  `references/matching.md` and the borderline cases: when the sources disagree with each other, the claim
  is Partly supported, with both passages quoted.
- A claim no source covers is attributed only to whoever the author got it from, which the user names,
  never to a provided source.
- New rule: differences are always written "draft says X; sources say Y" with the source id, and a fact is
  credited to the source that contains it ("both sources" only when each was quoted).
- The independent evaluation ran on 1.1.0.
